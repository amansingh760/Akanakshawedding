# Wedding Card Sender

Static site (no build step). Enter a guest name, get a personalised wedding card PDF
with the name written in Hindi, then download it, share it, or open WhatsApp with the invitation text.

## Files
- `index.html`: the whole app (HTML, CSS, JS)
- `assets/p1.jpg, p2.jpg, p3.jpg`: the three card pages
- `vercel.json`: Vercel settings

## Run locally
    npx serve .

## Deploy
Push to GitHub, import the repo in Vercel, framework preset "Other", no build command, output directory `.`
